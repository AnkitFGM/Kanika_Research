# Kanika Research Website

A standalone academic website built with HTML and CSS. No dependencies, backend, package installation, or build command are needed.

## Preview
Extract this ZIP and open index.html in a web browser.

## Free hosting on GitHub Pages
1. Sign in at https://github.com and create a PUBLIC repository named kanika-research. Initialise it with a README so it has a main branch.
2. Extract this ZIP. Use Add file > Upload files in your repository and upload index.html at the repository root. Upload .nojekyll too if your file picker shows it. Do not upload the ZIP itself or put index.html inside a subfolder. The included README can replace the initial README.
3. Commit the uploaded files to main.
4. Open Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select main and /(root), then Save.
7. Wait for deployment. The Pages settings will show the website link, typically https://YOUR-USERNAME.github.io/kanika-research/ . Publication may take up to 10 minutes.

GitHub Free supports Pages for public repositories. The website and source in this setup are public.

## Edit the content
Open index.html in a text editor, or use GitHub's file editor. Update the biography, research topic, laboratory and supervisor names, publications, institutional email, and profile links. Commit updates to main to republish.
All styling is inside the <style> element. The particle illustration is inline SVG, so no external image downloads are needed.
